# 🌍 Tu Destino - Trabajo Práctico Final (React + Vite)

Sitio web interactivo desarrollado para la agencia de viajes **"Tu Destino"** en el marco del Centro de e-Learning de la **UTN BA**.

---

## 🚀 Tecnologías Utilizadas
* **React** (con Vite)
* **React Router DOM** (v6) para la navegación multipágina con layout compartido y diseño flexible.
* **CSS3** (Estilos centralizados y modularizados en la carpeta `src/styles/`).
* **FontAwesome** para la iconografía.

---

## 📂 Estructura del Proyecto
```text
src/
├── assets/          # Imágenes y recursos locales
├── components/      # Componentes reutilizables (Navbar, Footer, Card, GalleryItem, Formulario, Layout)
├── pages/           # Vistas principales (Home, Servicios, Destino, Contacto)
├── styles/          # Hojas de estilo CSS (general.css, hero.css, cards.css, contact.css, gallery.css)
├── App.jsx          # Configuración de rutas (React Router)
└── main.jsx         # Punto de montaje de la app
